# OpenClaw Mobile - Phase 2

**Spark Agent Chat App**

## 功能

### ✅ Phase 1 (完成)
- 基本 Android App 架構
- GitHub Actions 自動編譯

### ✅ Phase 2 (完成)
- WebSocket 連接功能
- Spark Agent Chat 介面
- 訊息收發功能
- 自動重連機制
- 訊息泡泡 UI

## 技術

- **WebSocket**: OkHttp 4.12.0
- **UI**: Material Design
- **架構**: MVVM (簡化版)

## 使用

1. 安裝 APK
2. 自動連接至 `wss://artiforge.studio/ws/spark`
3. 開始與 Spark Agent 對話

## 下載

https://artiforge.studio/static/OpenClawMobile.apk
